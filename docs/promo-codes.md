# Промокоды

Активация доступна авторизованным пользователям в «Центре наград».
Генератора, панели управления и созданных по умолчанию кодов нет.

Настройки хранятся в `PromoCode`:

- `code`: уникальные латинские буквы в верхнем регистре, цифры, `_` или `-`; до 64 символов.
- `reward`: награда от 1 до 1 000 000 попкорнов.
- `active`: включение кода; новый код по умолчанию выключен.
- `startsAt`, `expiresAt`: начало и окончание в UTC; `NULL` означает отсутствие границы.
- `maxActivations`: общий лимит активаций; `NULL` означает отсутствие общего лимита.
- `redeemedCount`: счётчик успешных активаций; меняется приложением.

Каждый код можно активировать один раз на аккаунт. Учёт находится в
`PromoRedemption`; проводка баланса — в `PopcornEntry` с категорией `promo`.
Начисления не расходуют лимиты ежедневной активности или игр.
Награда, активация и счётчик сохраняются одной транзакцией. Повторный запрос
не начисляет награду второй раз. На аккаунт допускается 20 попыток за 15 минут.

Пример для будущего создания администратором в базе (это пример, он не выполняется
миграцией или приложением):

```sql
INSERT INTO "PromoCode" ("code", "reward", "active", "startsAt", "expiresAt", "maxActivations")
VALUES ('YOUR_CODE', 100, true, '2026-12-01 00:00:00', '2026-12-31 23:59:59', 500);
```

Для отключения нужно установить `active = false`. Не удаляйте историю активаций,
не сбрасывайте счётчики и не изменяйте код/награду после начала распространения;
для другой кампании создавайте отдельную запись.
