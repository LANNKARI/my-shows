# Мобильная навигация и поиск

Добавлены нижняя панель «Главная / Поиск / Библиотека / Профиль» и отдельная страница `/search`. Панель доступна на телефонах и планшетах до 1280px; на более широких экранах используется верхнее меню. Для вошедшего пользователя профиль ведёт на его страницу, для гостя — на вход. В мобильной библиотеке есть ссылки на существующие разделы «Смотрю», «В планах» и «Коллекции».

Под нижнюю панель зарезервирован отступ с учётом safe area и верхней границы. Модальные окна с z-index 50 остаются выше панели. Страница поиска и кнопка в шапке доступны без входа. Поле имеет размер текста 16px на телефоне, чтобы не провоцировать автоматическое увеличение в iOS.

Поиск использует существующий серверный TMDB API. Добавлены загрузка, отсутствие совпадений, ошибка с повтором, очистка и переход к результату с сохранением типа movie/tv. Запросы отменяются при изменении строки и уходе со страницы. На десктопе сохранён поиск в верхней панели; Escape закрывает подсказки, ArrowDown переводит фокус на первый результат, кнопки поддерживают Tab/Enter.

Схема базы и данные пользователей не меняются. Переработка главной, новая библиотека и быстрая отметка серии относятся к следующим этапам; здесь добавлена только навигация между существующими разделами.

## Проверка

```bash
npm ci
npx playwright install chromium
npm run build
npm run test:ui
```

При наличии системного Chromium вместо установки браузера можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium` для команды тестов. На Linux могут понадобиться системные библиотеки браузера; для CI Playwright поддерживает `npx playwright install --with-deps chromium`.

UI-тесты запускают production-сборку на локальном порту 3320. Ответы API подставлены тестами: настоящие Supabase, TMDB, Cloudinary и рабочие аккаунты не используются. Проверяются переходы и активные пункты, гость и вошедший пользователь, ширины 320/390/768/1279/1280/1440, отсутствие перекрытия нижней панелью, состояния поиска, отмена устаревшего запроса, повтор после ошибки, клавиатура и сохранение типа тайтла при импорте.

Эти проверки не подтверждают доступность реального TMDB или поведение клавиатуры на физическом iPhone. После выкладки следует проверить поиск с рабочим ключом и панель на реальном телефоне.
